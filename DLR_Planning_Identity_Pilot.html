What This Is

A structured initiative to help the Planning Discipline articulate and align around its shared identity so it can operate with greater consistency and clarity across DLR's complex, multi-sector matrix environment.

Pilot Approach: Why This Structure

This pilot balances broad inclusivity with focused synthesis work:

All 40 Planning team members shape the framework through structured input (Phase 1) and collective refinement (Phase 3).

A 10-person representative cohort (one member from each sector) handles the intensive pattern analysis and framework development work (Phase 2).

This approach ensures the Identity Framework reflects the full discipline's perspective and voice—across all sectors—without requiring 40 people to participate in every working session. It's efficient, inclusive, and produces a framework with shared ownership across the discipline.

Timeline: 6-8 weeks from launch to completion
Deliverable: Planning Identity Framework (v2.0) + strategic implementation recommendations

Pilot vs. Full Program

This pilot tests a structured, efficient approach to discipline identity development. Based on pilot outcomes, future engagements could follow one of two paths:

Pilot Model (What's Described in This Document)

  • All 40 members provide input via online questionnaire
  • 10-person representative cohort handles intensive synthesis work
  • All 40 members participate in half-day refinement session
  • Produces: Planning Identity Framework v2.0 with strategic implementation recommendations
  • Best for: Efficient scalability across multiple disciplines; rapid timeline; testing process effectiveness

Full Program Model

  • All 40 members provide input via online questionnaire
  • All 40 members participate in full-day collaborative working session structured in three phases:

Morning - Sector Deep Dive:

10 sector-specific tables (4 members each) identify what's working well, current challenges, and neutral elements within their sector context. Each sector prepares findings for group presentation.

Midday - Sector Report-Outs:

Each sector shares their findings with the full group, making visible the full landscape of Planning's reality across DLR and surfacing cross-sector patterns.

Afternoon - Collective Synthesis:

Facilitated full-group process (all 40) for collaborative pattern analysis, cross-sector learning, collective problem-solving, and framework co-creation. The group addresses challenges together and builds a unified Planning identity that honors sector-specific nuances.

  • Produces: Planning Identity Framework v2.0 with deeper collaborative ownership, enhanced cross-sector understanding, strengthened team cohesion, and collective solutions to sector-specific challenges developed through real-time co-creation
  • Best for: Maximum engagement; building collaborative capacity; deepening cross-sector relationships and mutual understanding; creating sophisticated framework that honors both unity and context

Key distinction: Both models produce a usable identity framework. The Full Program model adds significant value through the collaborative process itself—strengthening cross-sector relationships, building shared ownership through real-time co-creation, and developing collective solutions to discipline-wide challenges rather than review and refinement alone.

Current Context:

How the Pilot Works

Phase 1: Discipline-Wide Input (Week 1-2)

All 40 Planning team members complete a structured online questionnaire designed to surface patterns in how the discipline currently defines:

  • Its role and contribution within DLR's matrix
  • Its core strengths and differentiators
  • Its priorities and strategic direction
  • How it represents itself across sectors

Time commitment: 20-30 minutes per person
Deliverable: Input analysis and pattern synthesis report

Phase 2: Pilot Cohort Synthesis (Week 3-5)

A 10-person representative cohort (one member from each sector) participates in facilitated working sessions to:

  • Identify core themes and patterns from discipline-wide input
  • Clarify shared articulation of Planning's identity
  • Develop Planning's structured Identity Framework (draft v0.5)

Time commitment: Three 2-hour working sessions over 3 weeks (6 hours per participant; 60 aggregate hours)

Phase 3: Full Discipline Refinement (Week 6-8)

The full Planning Discipline (all 40 team members) participates in a facilitated session to:

  • Review the draft Identity Framework developed by the pilot cohort
  • Provide feedback and refinement input
  • Ensure alignment and shared ownership across the discipline
  • Validate practical usability across sectors
  • Finalize the Planning Identity Framework (v2.0)

Time commitment: One half-day session (3-4 hours, all 40 participants)

Professional deliverables:

  • Finalized Planning Identity Framework (v2.0)
  • Comprehensive synthesis report: patterns and themes from discipline-wide input
  • Strategic recommendations for framework implementation and integration
  • Guidance for ongoing use across cross-discipline collaboration and onboarding

What the Pilot Produces

Tangible Outputs:

  • Planning Identity Framework (v2.0) - documented and ready for operational use
  • Comprehensive synthesis report analyzing patterns from discipline-wide input
  • Strategic implementation recommendations
  • Integration guidance for cross-discipline collaboration and new planner onboarding

Strategic Value:

  • Clear articulation of Planning's role and contribution

  • Accelerated onboarding framework for new planners
  • Enhanced confidence in multi-discipline team participation

Why External Facilitation

  2. Pattern identification remains objective and free from internal bias

  4. Framework development follows proven methodology for matrixed organizations

  • Structured input methodology to surface authentic patterns
  • Facilitated synthesis to identify shared meaning
  • Framework architecture that produces durable, usable reference points
  • Alignment between discipline-level identity and DLR's broader organizational culture, ensuring coherence and integration across the matrix

This is not a one-time workshop, but a disciplined process that results in a documented identity framework the Planning Discipline can reference and operate from going forward.
